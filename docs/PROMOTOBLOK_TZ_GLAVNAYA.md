# PROMOTOBLOK — ТЗ на главную страницу

## 1. Цель

Сверстать рабочую главную страницу PROMOTOBLOK в браузере максимально близко к уже утверждённому визуальному макету.

Главная должна быть:
- настоящей HTML/CSS/JS-страницей;
- адаптивной;
- кликабельной;
- визуально соответствовать утверждённой версии;
- стать базовым шаблоном для всего остального сайта.

## 2. Главный источник истины

Визуальный эталон — утверждённая главная PROMOTOBLOK, которую уже согласовали.

При верстке нельзя:
- придумывать новый дизайн;
- менять цветовую систему;
- менять композицию;
- менять порядок блоков;
- добавлять новые блоки;
- удалять согласованные элементы;
- заменять стиль на «примерно похожий».

Если в макете есть конкретное решение — повторяем его.

## 3. Общая структура страницы

Порядок блоков строго такой:
1. Header
2. Hero
3. 4 основные группы
4. AI-консультант
5. «Есть на что посмотреть»
6. Полезные статьи
7. Нижние сервисные / доверительные блоки
8. Footer

Порядок не менять.

## 4. HEADER

Шапка должна соответствовать утверждённой главной.

Обязательные элементы:
- оригинальный логотип PROMOTOBLOK;
- кнопка / пункт «Каталог»;
- основные пункты навигации;
- контактная зона;
- элементы, которые есть в утверждённом макете.

Требования:
- высота шапки как в макете;
- те же отступы;
- тот же размер логотипа;
- тот же зелёный;
- без новых иконок и случайных элементов;
- шапка становится единым компонентом для всего сайта.

## 5. HERO

Hero должен повторять утверждённую концепцию.

Содержание:
- широкая тематическая фотография;
- семейная / загородная атмосфера;
- верхний текст: «ТЕХНИКА ДЛЯ УЧАСТКА, ДОМА И ФЕРМЫ»;
- заголовок: «Надёжная техника для ваших задач»;
- подзаголовок;
- CTA: «Перейти в каталог →».

Требования:
- композиция как в согласованной главной;
- текст не должен занимать слишком много пространства;
- изображение не должно быть случайным;
- цвет и контраст текста как в master;
- кнопка должна реально вести на `catalog.html`.

## 6. БЛОК 4 ОСНОВНЫХ ГРУПП

Строго 4 направления:
1. Земля и хозяйство
2. Газон и большие площади
3. Сад и участок
4. Умная и сезонная техника

Порядок фиксированный.

Визуально:
- не делать 4 огромные разноцветные карточки;
- использовать спокойную горизонтальную композицию;
- изображение + название + короткий список категорий;
- оформление должно соответствовать утверждённому макету.

### Земля и хозяйство
- Мотоблоки
- Мотоблоки с косилкой
- Мототракторы
- Минитракторы
- Навесное оборудование
- Прицепы и адаптеры

### Газон и большие площади
- Газонокосилки
- Садовые тракторы
- Райдеры
- Zero-turn
- Радиоуправляемые косилки

### Сад и участок
- Триммеры и мотокосы
- Бензопилы
- Воздуходувки
- Кусторезы
- Высоторезы
- Измельчители веток
- Бензорезы
- Электроинструмент

### Умная и сезонная техника
- Yarbo Core
- Снегоуборщики
- Мотобуксировщики

## 7. AI-КОНСУЛЬТАНТ

Расположение: сразу после 4 групп.

Назначение:
- простой умный продавец;
- помощь в выборе;
- не перегруженный чат;
- человекопонятный интерфейс.

Визуал:
- светлый / нежно-зелёный фон;
- компактный дружелюбный образ;
- без женского персонажа;
- стилистически продолжает верх страницы.

Содержание:
- заголовок;
- короткое объяснение;
- поле ввода;
- кнопка «Спросить».

Преимущества:
- Быстрые ответы 24/7
- Подбор техники под ваши задачи
- Актуальные цены и наличие
- Помощь в оформлении заказа

На первом этапе AI может быть фронтенд-заглушкой, но визуально блок должен быть готов.

## 8. БЛОК «ЕСТЬ НА ЧТО ПОСМОТРЕТЬ»

Расположение: сразу после AI.

Содержание:
- 4 товара;
- реальная старая цена;
- новая цена;
- визуально понятная выгода.

Не называть «Популярная техника».

Название: «Есть на что посмотреть».

Дополнительно Telegram CTA:
- «Хотите узнавать о таких предложениях первыми?»
- «Мы регулярно выкладываем реальные скидки и специальные цены в Telegram.»
- Кнопка: «Подписаться на Telegram →».

## 9. ПОЛЕЗНЫЕ СТАТЬИ

Раздел должен визуально продолжать стиль 4 основных групп.

Требования:
- единый формат изображений;
- без хаоса картинок;
- одинаковые размеры карточек;
- спокойная композиция;
- 3–4 статьи на desktop;
- адаптивная лента на mobile.

## 10. НИЖНИЙ СЕРВИСНЫЙ БЛОК

Должен содержать:
- доставка;
- сборка / подготовка техники;
- гарантия;
- помощь;
- контакты;
- адрес;
- карта;
- SEO / служебные ссылки.

Не превращать нижнюю часть в перегруженный информационный портал.

## 11. FOOTER

Footer должен быть:
- в том же стиле, что утверждённая главная;
- тёмный / нейтральный;
- аккуратный;
- функциональный;
- не перегруженный.

Включает:
- логотип;
- основные ссылки;
- контакты;
- режим работы;
- адрес;
- соцсети / Telegram;
- юридические ссылки.

## 12. ЦВЕТОВАЯ СИСТЕМА

Общий принцип:
- белый;
- натуральный зелёный;
- светло-зелёные / мятные подложки;
- тёмный текст;
- минимум декоративных цветов.

Запрещено:
- добавлять оранжевые, синие, красные акценты без причины;
- делать блоки разноцветными;
- использовать случайные цветовые бейджи.

## 13. ТИПОГРАФИКА

Принцип:
- крупные и ясные заголовки;
- короткие подзаголовки;
- хороший контраст;
- минимум декоративности.

Важно:
- сохранить визуальную иерархию master;
- не использовать слишком мелкий текст;
- mobile должен оставаться читаемым.

## 14. DESKTOP

Главная должна:
- иметь нормальную ширину контейнера;
- не растягиваться бесконечно;
- сохранять воздух;
- показывать 4 направления без ощущения каталожной каши;
- иметь визуальный ритм между блоками.

## 15. MOBILE

Mobile обязателен.

Требования:
- отдельная адаптивная компоновка;
- не просто ужатый desktop;
- удобная шапка;
- крупные кликабельные элементы;
- горизонтальные блоки преобразуются в вертикальные;
- AI-блок упрощается;
- можно убрать большую картинку робота;
- товары и статьи — в удобной мобильной сетке / ленте.

## 16. КЛИКАБЕЛЬНОСТЬ

На первом этапе должны работать:
- логотип → главная;
- «Каталог» → `catalog.html`;
- CTA hero → `catalog.html`;
- ссылки категорий → будущие страницы / временные роуты;
- карточки товаров → будущая карточка товара;
- статьи → будущая статья;
- Telegram → реальная или временная ссылка;
- контакты → кликабельные телефон / email.

## 17. ЧТО ЗАПРЕЩЕНО

При верстке нельзя:
- придумывать новый Header;
- менять логотип;
- менять 4 группы;
- менять порядок блоков;
- вставлять эмодзи вместо графики;
- использовать случайные стоковые картинки без связи с утверждённым визуалом;
- делать новую цветовую концепцию;
- добавлять «популярные категории»;
- добавлять отдельный подборщик на главную;
- добавлять лишние баннеры.

## 18. КРИТЕРИЙ ГОТОВНОСТИ

Главная считается готовой только если:
- визуально узнаётся как наша утверждённая главная;
- desktop соответствует master;
- mobile соответствует master;
- все основные кнопки работают;
- страница опубликована на GitHub Pages;
- нет временных заглушек, которые заметно ломают дизайн;
- эту же шапку и дизайн уже можно использовать как базу для каталога.

## 19. СЛЕДУЮЩАЯ ЗАДАЧА

Переверстать текущую главную в GitHub именно по этому ТЗ и по утверждённому визуальному master, без новых дизайнерских решений.
